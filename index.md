# Background Music Generator with any AI

**Background Music Generator with any AI** is a Windows desktop app by [3thousand30](https://3thousand30.com) for creating a single background-music track for videos, podcasts, product demos, focus content, and other spoken or visual work.

Bring your own AI provider key. BMG connects directly to the provider profile you choose: no BMG subscription, no BMG cloud account, and no uploaded music library.

[Get it on Microsoft Store](https://apps.microsoft.com/detail/9P6KHZWC9HNR){: .btn .btn-blue }

---

## How it works

1. **Add a Music API Profile** — enter your provider, API key, endpoint, and model once; BMG can save multiple named profiles.
2. **Choose a music persona and write a brief** — the persona sets a reusable musical direction, while your brief says what this track needs to do.
3. **Shape the output** — choose a template, duration, mood, genre, tempo, instruments, loop setting, format, and output folder.
4. **Generate and listen** — create one track, play it directly in BMG, check the Activity Log, and open its folder when you are ready to use it.

Each track is saved locally to the folder you select. Your Windows Music folder is the default.

---

## Key features

- **One-track workflow** — create and review a track before moving on to the next one
- **Music API Profiles** — save named provider, model, endpoint, and encrypted-key combinations
- **Provider flexibility** — use OpenRouter, Gemini (Lyria), Stable Audio, TemPolor, SOUNDRAW, or a custom endpoint
- **Music personas** — reusable musical directions with goals, sound, tempo range, rules, and a personal note
- **Output templates** — start from Product Demo, Podcast Intro, Documentary, Study & Focus, Creator Video, or your own editable template
- **In-app player and Activity Log** — listen immediately and see generation progress or errors without leaving the app
- **MP3 and WAV output** — choose the file format that best fits your editor or workflow
