# Troubleshooting

## Test connection does not work

Check that the API key is active, the Base URL is correct, and the model name exists for that provider account. Save the profile after changing the key, then test again.

## Generate does nothing or fails

Open the **Activity Log** in the header. It records when a request starts, the chosen profile, requested output, saved track path, and provider response. Use it to check whether the issue is the API key, account credit, model, endpoint, or request.

## The generated track does not play in BMG

Use **Show in folder** first to confirm the file was saved. If it is present, close and reopen BMG, then try the player again. If playback still fails, keep the Activity Log details and contact support.

## The provider generated a different length or format

Music providers can have their own length and output limitations. BMG sends the settings you choose, but the provider's response is authoritative. Try a duration or format offered by the selected model.

## Need help?

Email [hello@3thousand30.com](mailto:hello@3thousand30.com?subject=Background%20Music%20Generator%20support) and include the Activity Log message, provider name, model, and the action you were taking.
