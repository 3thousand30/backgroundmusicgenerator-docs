# Save & Listen

## Where tracks are saved

BMG starts with your Windows **Music** folder as the output location. On **2. Output**, click **Output folder** to choose a different location. The generated audio file is saved there.

Choose **MP3** for broad compatibility and a smaller file, or **WAV** when your editing workflow needs an uncompressed file.

## MP3 details

Before generating an MP3, use the **MP3 details** row on **2. Output** to add its **Title**, **Contributing artists**, **Album**, and **Track number**. The title is prefilled from the Track name, while the other fields are optional.

BMG embeds the details in the MP3 file itself. In Windows File Explorer, they appear in columns such as **Title**, **Contributing artists**, **Album**, and **#**. The fields are available only for MP3 because BMG writes standard MP3 tags; WAV is saved without these details.

## Listen in BMG

After generation, BMG displays the player at the top of the Output step and loads the saved file automatically. Use the standard play, seek, volume, and menu controls, or choose **Show in folder** to open the file location.
