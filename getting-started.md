# Getting started

This is a placeholder for the complete getting-started guide.

1. Open the key icon and add a Music API Profile.
2. Select a persona and describe the music you need.
3. Choose the output details, generate one track, and listen in the app.

The complete guide will cover profile setup, testing a connection, output folders, and playback.
